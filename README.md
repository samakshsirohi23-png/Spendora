# Spendora 💰
### Expense Intelligence & Budget Management System

Spendora is a Python-based expense management
system designed to help students manage their
income, expenses and monthly budgets.

## Features
- Income Management
- Expense Tracking
- Monthly Budget Management
- Budget Alerts
- Expense Analysis
- Financial Insights
- Monthly Reports
- CSV Data Storage

## Technologies Used
- Python
- CSV File Handling
- Datetime
- OS Module

## How to Run

Run the following command:

py spendora.py
